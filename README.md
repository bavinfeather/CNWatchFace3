# 几何旷野 SOL / Geometric Wilderness SOL

Garmin Connect IQ 山景数据表盘。

[English](README.en.md)

## 功能

- 时间、日期、农历和节气
- 可自定义数据行及顶部进度指标
- 可选择显示日出、日落信息
- 中文和英文显示、时间字体与个性文字设置
- 支持 AMOLED 常亮显示

可用数据取决于手表型号和设备提供的数据。支持的型号见 [manifest.xml](manifest.xml)。

## 构建

安装 Garmin Connect IQ SDK 和 VS Code 的 Monkey C 扩展，打开本项目后运行 **Monkey C: Run Without Debugging**。使用 **Monkey C: Export Project** 生成 IQ 包。
