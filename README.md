# 几何旷野 SOL / Geometric Wilderness SOL

Garmin Connect IQ 山景数据表盘。

[English](#english)

## 功能

- 时间、日期、农历和节气
- 可自定义数据行及顶部进度指标
- 可选择显示日出、日落信息
- 中文和英文显示、时间字体与个性文字设置
- 支持 AMOLED 常亮显示

可用数据取决于手表型号和设备提供的数据。支持的型号见 [manifest.xml](manifest.xml)。

## 构建

安装 Garmin Connect IQ SDK 和 VS Code 的 Monkey C 扩展，打开本项目后运行 **Monkey C: Run Without Debugging**。使用 **Monkey C: Export Project** 生成 IQ 包。

素材来源及许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## English

A mountain-themed Garmin Connect IQ watch face.

- Time, date, Chinese lunar date, and solar terms
- Configurable data rows and a top progress indicator
- Optional sunrise and sunset information
- Chinese and English display, time fonts, and custom text
- AMOLED always-on display

Available data depends on the device. Supported models are listed in [manifest.xml](manifest.xml).

To build, install the Garmin Connect IQ SDK and Monkey C extension for VS Code, open this project, and run **Monkey C: Run Without Debugging**. Use **Monkey C: Export Project** to create an IQ package.
